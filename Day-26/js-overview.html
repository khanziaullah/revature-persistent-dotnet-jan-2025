JavaScript Overview

JavaScript is the programming language of the web. It runs in the browser and makes HTML documents interactive — responding to user actions, updating the page dynamically, and communicating with servers without reloading.

// Output

Data Types (Primitives and Objects)

JavaScript has two categories of data types. Primitives are simple, immutable values — strings, numbers, booleans, null, undefined, and symbols. Objects are collections of key-value pairs, including arrays and functions.

// Output

Variables (var, let, const)

Variables are named containers for storing values. JavaScript has three ways to declare them — var (old, function-scoped), let (block-scoped, reassignable), and const (block-scoped, cannot be reassigned).

// Output

Type Coercion

Type coercion is JavaScript's automatic conversion of one data type to another during an operation. It can produce surprising results — understanding it helps you avoid bugs and explains why === is preferred over ==.

// Output

Strict Mode

Strict mode is an opt-in mode that catches common mistakes and disables certain unsafe JavaScript features. You enable it by writing "use strict" at the top of a file or function. Modern ES modules use it by default.

// Output

Arithmetic Operators

Arithmetic operators perform mathematical calculations. JavaScript supports the standard operators plus modulo (remainder), exponentiation, and increment/decrement shortcuts.

// Output

Comparison and Logical Operators

Comparison operators compare two values and return true or false. Logical operators combine multiple conditions. The key rule: always use === (strict equality) instead of == to avoid type coercion surprises.

// Output

Assignment Operators

Assignment operators assign a value to a variable. Shorthand operators combine an arithmetic operation with assignment — making code more concise without changing behavior.

// Output

Control Flow (if/else, switch, loops)

Control flow determines the order in which code executes. Conditional statements (if/else, switch) make decisions. Loops (for, while, for...of) repeat code until a condition is met.

// Output

Array and Array Methods

An array is an ordered list of values. JavaScript arrays come with powerful built-in methods — push/pop for adding/removing, map for transforming, filter for selecting, and reduce for aggregating.

// Output

Functions — Declaration and Expression

A function is a reusable block of code. Function declarations are hoisted — they can be called before they appear in the file. Function expressions assign a function to a variable and are not hoisted.

// Output

Arrow Functions

Arrow functions are a shorter syntax for writing functions introduced in ES6. They are especially useful for callbacks and array methods. They also handle the "this" keyword differently from regular functions.

// Output

Default Parameters

Default parameters let you define fallback values for function arguments. If a caller does not pass a value for that argument, the default is used instead of undefined.

// Output

Object Literals

An object literal is a collection of key-value pairs wrapped in curly braces. Objects represent real-world entities — a user, a product, a config. Values can be primitives, arrays, or other objects.

// Output

Template Literals

Template literals are strings wrapped in backticks instead of quotes. They support multi-line strings and embedded expressions using ${} — making string building far cleaner than concatenation with +.

// Output

this Keyword

this refers to the object that is currently executing the code. Its value depends on how a function is called — inside a method it points to the owning object, in a regular function it points to the global object, and in arrow functions it is inherited from the surrounding scope.

// Output

Classes (ES6)

Classes are a clean ES6 syntax for creating objects from a blueprint. Under the hood they use JavaScript's prototype system, but the class syntax makes object-oriented code more readable and familiar.

// Output

Constructors

A constructor is a special method inside a class that runs automatically when a new instance is created. It sets up the initial state of the object by assigning values to its properties using this.

// Output

Methods

Methods are functions defined inside a class that describe what instances of that class can do. They are shared across all instances via the prototype — not copied into each object individually.

// Output

Variable Scopes (Global, Function, Block)

Scope determines where a variable is accessible. Global scope means accessible everywhere. Function scope means accessible only inside a function. Block scope (let/const) means accessible only inside the nearest curly braces.

// Output

Hoisting

Hoisting is JavaScript's behaviour of moving declarations to the top of their scope before code runs. Function declarations are fully hoisted. var is hoisted but initialised as undefined. let and const are hoisted but not initialised — accessing them early causes a ReferenceError.

// Output

Closures

A closure is a function that remembers the variables from its outer scope even after that outer function has finished executing. Closures are one of the most powerful and widely used features in JavaScript.

// Output

Spread and Rest Operators

Both use the ... syntax but serve opposite purposes. Spread expands an array or object into individual items — useful for copying and merging. Rest collects multiple individual arguments into a single array — useful in function parameters.

// Output

Destructuring (Arrays and Objects)

Destructuring is a shorthand syntax that extracts values from arrays or properties from objects into individual variables. It eliminates repetitive access patterns and makes code cleaner.

// Output

Error Handling (try-catch)

try-catch lets you handle errors gracefully instead of crashing the program. Code in the try block runs normally — if an error occurs, execution jumps to the catch block. The finally block always runs, whether or not an error occurred.

// Output

DOM Structure

The DOM (Document Object Model) is the browser's live representation of your HTML as a tree of objects. Every tag becomes a node — and JavaScript can read, add, remove, or change any of them at any time.

Events and Event Listeners

Events are things that happen in the browser — a click, a keypress, a form submission, the page loading. addEventListener attaches a function (handler) to an element that runs whenever that event fires.

When an event fires, JavaScript automatically passes an event object to your handler function. This object contains details about what happened — which key was pressed, where the mouse was, which element was clicked, and more.

Event Bubbling and Capturing

When an event fires on an element, it travels through the DOM in two phases. Capturing goes top-down from document to the target. Bubbling goes bottom-up from the target back to document. By default, listeners use bubbling.

JSON (JavaScript Object Notation)

JSON is a text format for representing structured data. It looks like a JavaScript object but is always a string when transmitted. JSON.stringify() converts an object to a JSON string, and JSON.parse() converts it back.

// Output

Promises

A Promise is an object representing the eventual result of an asynchronous operation. It starts as pending, then either resolves (success) or rejects (failure). You chain .then() for success and .catch() for errors.

Fetch API

fetch() is the built-in browser function for making HTTP requests. It returns a Promise that resolves to a Response object. You call .json() on the response to parse the body as JSON — which also returns a Promise.

async/await Keywords

async/await is syntactic sugar over Promises that makes asynchronous code look and read like synchronous code. An async function always returns a Promise. await pauses execution inside the function until the Promise resolves.
