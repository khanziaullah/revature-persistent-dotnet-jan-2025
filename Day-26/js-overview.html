JavaScript Overview

JavaScript is the programming language of the web. It runs in the browser and makes HTML documents interactive — responding to user actions, updating the page dynamically, and communicating with servers without reloading.

Data Types (Primitives and Objects)

JavaScript has two categories of data types. Primitives are simple, immutable values — strings, numbers, booleans, null, undefined, and symbols. Objects are collections of key-value pairs, including arrays and functions.

// Output

Variables (var, let, const)

Variables are named containers for storing values. JavaScript has three ways to declare them — var (old, function-scoped), let (block-scoped, reassignable), and const (block-scoped, cannot be reassigned).

// Output

Type Coercion

Type coercion is JavaScript's automatic conversion of one data type to another during an operation. It can produce surprising results — understanding it helps you avoid bugs and explains why === is preferred over ==.

// Output

Strict Mode

Strict mode is an opt-in mode that catches common mistakes and disables certain unsafe JavaScript features. You enable it by writing "use strict" at the top of a file or function. Modern ES modules use it by default.

// Output

Arithmetic Operators

Arithmetic operators perform mathematical calculations. JavaScript supports the standard operators plus modulo (remainder), exponentiation, and increment/decrement shortcuts.

// Output

Comparison and Logical Operators

Comparison operators compare two values and return true or false. Logical operators combine multiple conditions. The key rule: always use === (strict equality) instead of == to avoid type coercion surprises.

// Output

Assignment Operators

Assignment operators assign a value to a variable. Shorthand operators combine an arithmetic operation with assignment — making code more concise without changing behavior.

// Output

Control Flow (if/else, switch, loops)

Control flow determines the order in which code executes. Conditional statements (if/else, switch) make decisions. Loops (for, while, for...of) repeat code until a condition is met.

// Output

Array and Array Methods

An array is an ordered list of values. JavaScript arrays come with powerful built-in methods — push/pop for adding/removing, map for transforming, filter for selecting, and reduce for aggregating.

// Output

Functions — Declaration and Expression

A function is a reusable block of code. Function declarations are hoisted — they can be called before they appear in the file. Function expressions assign a function to a variable and are not hoisted.

// Output

Arrow Functions

Arrow functions are a shorter syntax for writing functions introduced in ES6. They are especially useful for callbacks and array methods. They also handle the "this" keyword differently from regular functions.

// Output

Default Parameters

Default parameters let you define fallback values for function arguments. If a caller does not pass a value for that argument, the default is used instead of undefined.

// Output

Object Literals

An object literal is a collection of key-value pairs wrapped in curly braces. Objects represent real-world entities — a user, a product, a config. Values can be primitives, arrays, or other objects.

// Output

Template Literals

Template literals are strings wrapped in backticks instead of quotes. They support multi-line strings and embedded expressions using ${} — making string building far cleaner than concatenation with +.

// Output

Naming Conventions

Naming conventions are agreed-upon patterns for naming variables, functions, and other identifiers. Following them makes code readable and predictable — for yourself and for teammates.
